# Declaração de Uso de Inteligência Artificial (AI_DECLARATION.md)

Este documento registra de forma transparente a natureza e o escopo do auxílio de ferramentas de Inteligência Artificial utilizados durante o desenvolvimento do projeto **Simulador de Batalha - PokeSal**.

---

## 1. Conformidade com as Regras do Projeto
- **Requisitos Autorais:** Declaramos explicitamente que os 3 requisitos autorais obrigatórios do projeto foram concebidos, detalhados e implementados inteiramente pela equipe, **sem nenhum auxílio de Inteligência Artificial**, cumprindo rigorosamente a regra do edital.
- **Escopo do Apoio de IA:** O uso de IA foi restrito exclusivamente a consultas de apoio técnico de formatação de código, padrões de documentação (Javadoc) e suporte a comandos de versionamento (Git).

---

## 2. Histórico de Prompts Utilizados
Abaixo estão listados os comandos e consultas de texto permitidos enviados à ferramenta de IA durante o processo de desenvolvimento:

1. **Versionamento de Código:**
   > `git pull conflito de alteracoes locais no workspace`

2. **Padrão de Documentação:**
   > `sintaxe javadoc para metodos em interfaces java`

3. **Boas Práticas de Linguagem:**
   > `exemplo de estrutura try-catch em java para tratamento de excecoes de inventario`

---

## 3. Resumo das Atividades Apoiadas
- Auxílio na resolução de comandos de gerenciamento de repositório Git (`git stash` e `git pull`).
- Consulta sobre a sintaxe padrão de Javadoc para conformidade com o Checkstyle do projeto.
- Dúvidas gerais sobre tratamento sintático de exceções em Java.
